# StealthBridge Community Code of Conduct

StealthBridge is a public, privacy-conscious financial infrastructure engineering project on Stellar. Respectful, technically rigorous collaboration is required across all repositories (`stealthbridge-contracts`, `stealthbridge-backend`, `stealthbridge-sdk`, `stealthbridge-frontend`, and `.github`).

## Commitments

Contributors and maintainers pledge to treat everyone professionally across issues, pull requests, code reviews, and technical discussions regardless of experience, background, or identity.

### Expected behavior

- Ground reviews in reproducible evidence, tests, threat models, and specifications rather than personal criticism.
- Welcome newcomers, explain architectural context clearly, and credit prior authors and upstream libraries (`OpenZeppelin/stellar-contracts`, `NethermindEth/stellar-private-payments`, Stellar Smart Account Kit).
- Handle security disclosures privately via [SECURITY.md](SECURITY.md) rather than public issue threads.
- Disclose material conflicts of interest on financial rails, issuer decisions, or governance proposals.

### Unacceptable behavior

- Harassment, discrimination, intimidation, doxxing, or abusive commentary.
- Publishing private keys, mnemonic phrases, shielded note secrets, zero-knowledge proof witnesses, live credentials, or customer KYC data.
- Fabricating audit results, Testnet/Mainnet telemetry, fake payment confirmations, or deceptive security claims.

## Enforcement

Report conduct concerns privately to organization maintainers without posting sensitive personal details publicly. Maintainers may edit offending content, close threads, or restrict repository access to protect community members and user safety.
