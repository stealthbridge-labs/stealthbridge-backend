# Support — StealthBridge Backend

> **Stellar Testnet engineering only.** StealthBridge does not accept customer funds, hold custodial Mainnet keys, or execute fiat bank payouts.

## Where to get help

- **Rust / Axum API, SQLx migrations, and Stellar RPC issues:** Search [stealthbridge-backend issues](https://github.com/stealthbridge-labs/stealthbridge-backend/issues) and consult [docs/INTEGRATION-GUIDE.md](docs/INTEGRATION-GUIDE.md) and [docs/PRODUCTION-SQLX-MIGRATION-RUNBOOK.md](docs/PRODUCTION-SQLX-MIGRATION-RUNBOOK.md).
- **Frontend UI & BFF routes:** Use [stealthbridge-frontend](https://github.com/stealthbridge-labs/stealthbridge-frontend/issues).
- **SDK schemas & OpenAPI parity:** Use [stealthbridge-sdk](https://github.com/stealthbridge-labs/stealthbridge-sdk/issues).

Include redacted logs, Postgres version, `cargo test` output, and the target commit hash. Never share database URLs, `STEALTHBRIDGE_ACCOUNT_BRIDGE_SECRET`, wallet secrets, or user PII.

For security disclosures, follow [SECURITY.md](SECURITY.md) privately.
